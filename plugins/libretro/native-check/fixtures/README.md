These four original test programs are dedicated to the public domain under
CC0-1.0. They contain no downloaded game code or assets. The check encodes the
Lua source into the native TIC-80 CODE chunk and compiles the WAT source into
an ordinary WASM-4 cartridge on the build host. LowRes NX and PuzzleScript
fixtures are their original text formats. Fixtures are check inputs only;
none is installed in runner packages.
